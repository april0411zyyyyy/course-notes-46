# course-notes-46
> 学号后两位：46
开源课程笔记静态站点，整理计算机专业课程学习笔记，网页直接打开浏览，任何人可以提交补充笔记。

## ✨ 项目介绍
本项目是静态课程笔记网站，使用HTML+CSS实现，无后端，轻量化，方便同学查阅、补充课程笔记。
包含：C语言、数据结构、高等数学、Linux、Python等课程笔记。

## 📖 使用方式
1. 克隆仓库：`git clone https://github.com/april0411zyyyyy/course-notes-46.git`
2. 直接打开 index.html 即可浏览笔记
